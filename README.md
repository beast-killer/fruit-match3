# 水果消消乐 🍉

一个纯前端、无需安装的 10×10 水果三消小游戏。所有游戏代码都在这一个 HTML 文件里，双击即可离线游玩。

## 玩法

- 点击或滑动交换相邻的水果
- 3 个及以上同款水果横向或纵向连成一线即可消除
- 初始 30 步，连续掉落会触发连击并获得更高分数
- 当棋盘没有可用交换时，会提示并自动重新洗牌
- 步数用尽后显示本轮得分，最高分会保存在浏览器本地

## 运行

直接双击 `水果消消乐.html`，或在浏览器中打开该文件。

游戏不依赖任何第三方库、字体或网络资源，CSS 和 JavaScript 均已内嵌在 HTML 中。

## 实现要点

- 10×10 棋盘，🍎🍊🍇🍓🍉🍒 六种水果
- 开局自动避免三连，并保证存在可消除的交换
- 支持鼠标点击、拖拽和手机触屏滑动操作
- 消除放大消失、水果掉落、得分飘字与连击提示
- 无可用步数时自动检测并打乱棋盘
- 响应式界面，适配桌面与移动端

## 兼容性

建议使用较新版本的 Chrome、Edge、Safari 或 Firefox。
